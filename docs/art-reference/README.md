# 网站美术参考库｜索引 v1.1

> 这是网站的**设计参考索引**，不是将插画公开展出的页面。相关原图保存在个人私人文件库（`/网站美术参考库/`），不直接提交到公开仓库。

## 使用目标

为个人网站的博客、摄影、艺术收藏和其他独立页面收集配色与视觉参考。重点尊重**整体色彩关系、冷暖张力和光感**，同时保持页面干净。允许不同页面采用不同的色彩甚至跳脱的布局。

## 两层分类

### 喜爱程度（首批暂定）

| 等级 | 含义 | 当前数量 |
|---|---|---:|
| S | 特别喜欢，核心设计参考 | 3 |
| A | 很不错，重点收藏 | 0 |
| B | 还不错，辅助参考 | 3 |
| C | 待评价，暂存候选 | 0 |

等级可以调整；**图像编号不可因调整等级而改变**。此排序只记录使用者个人偏好，不代表对作品质量的客观评价。

### 多维标签

同一张图允许拥有多个标签：

- **颜色**：冷蓝、冰蓝、暖白、金色、褐色、绿色、亮红、粉色等。
- **整体配色**：蓝白、褐蓝、蓝白金黑、绿蓝粉白等。
- **光感**：清透、金色暖光、斑驳日光、局部粉红暖光等。
- **色彩关系**：冷暖张力、强烈对比、柔和融合等。
- **设计用途**：首页、文字页、摄影集、收藏页或独立专题页。仅为可能用途，不预先绑定。

## 网站设计中如何使用

1. 先读 [个人网站视觉设计原则](../个人网站视觉设计原则.md)。
2. 再查看本索引，以及私人素材库里的**图片原图**；标注哪些是用户明确偏好，哪些只是助手推测。
3. 不要机械提取单一色号；优先观察整体配色、光感和视觉张力。
4. 网站不同页面可以有差别很大的设计，但必须有基本可用性、阅读和导航体验。
5. 不直接把第三方参考插画部署到公开网站；确认授权或使用原创图片后才能公开展示。
6. 发生重要审美偏好变化时更新本索引、私人目录数据及相关视觉原则，不只是留在聊天里。
